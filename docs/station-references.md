# 青岛站模型资料与精度边界

模型文件：`src/station.ts`。对象为 2008 年改建后的青岛站站房，包含保留的钟楼及历史站房（现胶济铁路青岛博物馆）、东翼、西翼、南翼与院内现代雨棚概貌。不是 1904 年原站的原样复建，也不是测绘级数字孪生。

## 已读取的资料

- [青岛日报／青报网：盘点各时期的青岛火车站，2016-09-22](https://www.dailyqd.com/arc/2016-09/22/content_352743.htm)。实际查看文末“现在的青岛火车站”照片，观察现代钟楼、石砌钟盘山墙、红瓦尖顶、黄色墙面、灰石勒脚、三拱入口、现代翼楼拱窗和老虎窗。
- [该现代站房照片](https://pic.dailyqd.com/uploadfiles/hw/dangan/img/attachement/jpg/site3/20160922/d8cb8a9d558a194ddfb310.jpg)。仅作为外形与比例研究参考；不作为模型贴图，也不随公开网页分发。模型内钟盘、牌匾、瓦面与石材纹理均为自行程序化绘制。
- [青报网：奥运会年青岛铁路新客站运营，2014-07-25](https://www.dailyqd.com/arc/2014-07/25/content_97816.htm)。证实 2008 年启用后的东、西、南三面 U 形站房和横跨东西的景观连廊；作为当代总体布局资料。
- [山东地情档案：建筑库“第六辑交通、邮电建筑”](https://shandong-chorography.org/database/a/section/44/article/226/)。档案是历史建筑说明，记载青岛站钟楼 35 米、三个拱券门、入口上部半木构山墙、粗毛石和黄色粉刷。不能直接当作当代改建站房的完整施工图。
- `public/data/scene.json` / OpenStreetMap：米制平面轮廓与位置。东翼 `way/1465995439`；西南翼 `way/1465995441`；保留的历史站房／博物馆 `way/1465995440`；实际站台雨棚 `way/1530312334`。四者全部从普通程序化楼房生成中排除，以免重叠。

## 参数来源

| 参数 | 模型处理 | 可信度／限制 |
|---|---|---|
| 地理位置、主要站房基座轮廓 | 使用上述三个 OSM polygon；X 向东、Z 向北，单位米 | 来自 OSM，未经现场测绘复核 |
| 东、西、南 U 形布局 | 依据 OSM 平面和青报网现代改建报道 | 有现代资料支持 |
| 东西翼主要屋顶总高 | 使用 OSM `height=22.14` 米作为控制值 | 数据标签值，不等于已核验设计标高；墙檐／屋脊分配为照片估计 |
| 钟楼高度 | 以历史档案 35 米为比例控制值，红星附近为 35 米 | 35 米属于历史说明；现代改建钟楼实际高度未取得一手实测，本模型不声称现代高度精确 |
| 钟楼平面及具体位置 | 位于历史站房南端、东南角；约 12.2 米方形塔身 | 依据 OSM 博物馆轮廓及照片相对尺度估计 |
| 瓦顶、钟楼石山墙、拱门、门窗、装饰线 | 依据 2016 现代实景重构 | 原创参数化几何；细节数量、间距、色彩非实测 |
| 历史入口三拱 | 历史站房东立面恰好三个主门洞 | 源于档案及照片；不是把三拱重复铺满全站 |
| 半木构 | 保留入口山墙的少量分格，现代表面以照片中的石饰／浅黄色为主 | 历史文字与现代照片外观有差异，采用克制的演绎，未声称材料原样保存 |
| 地面标高 | 使用传入 DEM 采样；站房统一水平地坪取 footprint 样点最大值 | 粗分辨率 DEM 无法提供建筑平台和地下室施工标高 |
| 站台雨棚 | 采用 OSM `way/1530312334` 的实际 polygon，长约 467.65 米，宽约 121.96 米；标签 min_height=22、height=26、roof:height=4、roof:shape=round | 轮廓及控制高度来自 OSM；拱形截面由标签推定，不等同工程结构图；不虚构月台和轨道 |
| 景观连廊 | 横跨东西站房的简化体量 | 存在性由青报网报道支持；准确走向、细节、标高为概貌 |

## 工程实现

按材质合批生成约 15 个可见 mesh，另一个简化碰撞 mesh。共享程序纹理采用 mipmap、三线性过滤和各向异性过滤；钟盘、门窗、瓦面、立面和红瓦屋脊可在近景与空中识别。模型可整体替换为未来的授权摄影测量／人工 glTF 资产。

接口：`buildStation(scene, data, shadows, sampleHeight)` 返回 `meshes`、`collisionMeshes`、`position`、`excludedIds: Set<string>` 和 `dispose()`。`position` 是全站相机观察目标，不是钟楼准确地理点。建议相机从东南看向该目标，`alpha=-0.62`、`beta=1.13`、`radius≈265`，近景钟楼则看向 `(-703.5, DEM平台+19, 322)`。

Demo 的“青岛站”导航优先聚焦钟楼和历史入口：相机目标 `(-715, DEM平台+14, 348)`，alpha=-0.48、beta=1.36、radius=130。滚轮拉远可查看现代翼楼和源图形雨棚。
