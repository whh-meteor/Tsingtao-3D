# 老城特色建筑资料与模型范围

本轮实现：`src/heritage-buildings.ts`。位置、轮廓和朝向来自 Geofabrik 山东 2026-10-11 OSM PBF 提取的 `public/data/heritage.json`，米制 AEQD 原点为经度 120.3163、纬度 36.0603，X 东、Z 北。地面由外部 DEM 采样；各独立建筑采用轮廓最高采样值作为整平基准，基座向下接地。

这里的模型是供实时浏览器场景使用的程序化外观复原，不是建筑测绘成果。建筑占地为真实 OSM 轮廓；没有 OSM 标签或文字资料佐证的层高、屋面分块、窗距、石饰、牌匾和颜色均为照片估计。模型没有室内，也没有将地图普通住宅批量冒称历史建筑。

## 总督府与总督官邸：两个独立对象

| 对象 | OSM 轮廓 | 有来源的参数 | 当前照片估计参数 |
| --- | --- | --- | --- |
| 德国总督府旧址 | way/403383420，约 X282、Z475 | 市政府资料记载 1903–1906 年、凹字平面、三纵五段、主体约 20m、花岗岩、折线红瓦屋顶、弧形屋面窗和铁栏 | 檐口 14m、屋面最大升高 6m；中央入口与上方小山花、两侧窗列、石饰和屋顶栏杆按实景估计 |

总督府的灰石对称办公楼与官邸的黄墙不对称住宅分别采用独立轮廓、材料和相机视点。代码没有把二者当成同一座建筑。

2026-10-14 浏览器复核修正：原入口错误地放在最长东翼墙段的中点 `[301.114,454.071]`。现在联合两翼与中央凸出的所有最前排同向 OSM 墙段，以84.081m整条前立面的投影中点建立中轴，再把中轴落到真实中央凸出墙段上。入口中心的平面基准是 `[276.586,456.043]`，中央凸出宽度14.344m来自 OSM，而非原先任意17.3m宽装饰面。入口、牌匾和中央竖窗同轴；取消被前凸石面遮挡的旧窗，并将正立面照片中的小三角山花作为6.4m宽、2.15m高的照片估计饰面。没有把官邸的宽波浪形山墙继续放在府楼中央，官邸模块未修改。

## 青岛啤酒博物馆

真实馆址为登州路56号。OSM 博物馆场地 `way/554250276` 的平均点约 X2286、Z2069；它是场地边界，不是可以整块挤出的站房。最初候选中心 X1685、Z1850 已纠正，模型没有复用错误窗口内的公寓和医院。

当前仅对实际馆区内四个明确的沿街厂房轮廓建立独立工业外观：`way/554250269`、`way/554250271`、`way/554250273`、`way/554250279`。采用红砖、粗石勒脚、白色拱窗框和灰绿色坡顶。檐口9.8m、两层窗、屋面升高最多4.6m为照片估计，不是官方测绘高度。门头文字是独立绘制的字样。

- [博物馆官方历史介绍](https://www.tsingtaomuseum.com/category/1773519016732667906)：厂区始于1903年。
- [官方工业建筑介绍](https://www.tsingtaomuseum.com/category/1773555496326803458)：1911年酿造建筑及原始图纸的保存。
- 实际查看的[官方建筑外观照片](https://qp-bowuguan-web.oss-cn-qingdao.aliyuncs.com/2025/3/31/1906520581642903553.jpg)：红砖、灰绿坡顶、白色顶部拱窗框和灰色基座。

数据没有给出可信烟囱点时不虚构烟囱坐标。模块已支持馆区250m内 `man_made=chimney` 的已测 OSM node，取得可信位置后自动生成；现在该条件没有命中。尚未复原未确认的生产线、博物馆内部和所有厂区辅助建筑。

## 大学路鱼山路红墙

OSM `way/556455087` 是开放三边墙线：`[907.760,96.627] → [1095.081,193.649] → [1117.925,149.912] → [929.774,55.607]`。墙线按真实米制位置逐段贴地，程序估计灰石墙脚0.55m、红墙到2.65m、白色檐线到2.83m、金色瓦顶到3.15m。

真正大学路/鱼山路交汇道路节点约 `[898.426,96.371]`，因此网红墙相机和铭牌设于墙首点附近，不能把东端 `[1095,194]` 当成路口。OSM 未闭合的西侧44m边没有全部编造补齐；仅用实景支持的4m短转角表现鱼山路牌所在的另一面，并在此明确它属于照片估计的建筑细节。

- [2023年官方修缮项目报道](https://www.qingdaonews.com/app/content/2023-06/16/content_23456273.htm)：红墙、黄色琉璃瓦、白色路牌、总长468m。
- 实际查看[路口外观](https://www.qingdaonews.com/app/pic/2023-06/16/c5e7191d-7e52-4014-8c25-d45c72b9f79e.jpeg.2)和[路牌细部](https://www.qingdaonews.com/app/pic/2023-06/16/fbfe8506-ae5a-4287-90a2-b62d03e038fd.jpeg.2)。程序自己绘制大学路、鱼山路铭牌，不把新闻照片用作贴图。

## 工程与验收

所有程序纹理为原创砖缝、瓦片、石块、粗灰饰面和文字。研究原图只保存在被 Git 忽略的 `artifacts/heritage-research/`；不放入 `public/`，不包含在部署包。模型按地标与共享材质合批，47个可见网格、5个地标碰撞网格；近景玻璃/窗框/屋顶铁栏可以由 `setDetail(distance)` 在远处关闭。

屋顶用真实凹形轮廓的距离场坡面，不以中心大金字塔覆盖庭院。水平地形距离控制三角细分；法线采用 Babylon 左手坐标对应的绕序。2026-10-14 修正后的 NullEngine 检查结果：72,321三角形，所有顶点有限，31,418个屋面/瓦面三角形没有向下法线。该检查验证几何和方向；实际造型、遮挡和画面还应由主场景浏览器截图复核。

后续适合优先用测绘或有授权的 Blender/GLB 资产替换官邸复杂屋面、水产馆、府楼真实折线屋面与博物馆烟囱。原有坐标、名称、来源和排除ID接口可保持不变。
