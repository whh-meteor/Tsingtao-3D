# 青岛前海沙滩数据、材料与实现依据

核对日期：2026-10-14。此次只复原数据中已有的沙滩，不将所有近海海岸改成沙面。

另保留4个前海/石老人附近没有明确名称的真实沙面ID：439263572、449891147、813134069、820900326。这里面积是当次OSM轮廓在项目米制投影下计算的面积，不是官方浴场全域面积或当前潮位露出面积。

沙滩湿边由真实OSM海岸线与沙滩邻域相交获得，不采用“多边形最南端”等猜测。网格先在Python离线以5米方格裁切原轮廓，再约束三角化；仅方格内部参与处理，不将完整方格覆盖海面。洞和碎片轮廓完整保留。

小型岩石只生成在已映射岩礁/裸岩的近滩区域：`way/847959149` 与 `way/1465225541`。这些是源轮廓控制；每块石头的位置、露出高度、形状仍是估算，未取得潮间带测绘。没有为每个沙滩随机撒礁石。

## 模型与光照

`createBeachSurface(data,rawSampler?)` 是纯表面采样函数，可在GPU网格创建前供地形与步行碰撞共用。`rawSampler` 应采原始DEM，不能采已套此坡面的地形以免递归。若未提供，内陆端使用原场景海岸最低2.4米。海岸线处约0.12米，24米范围内平滑连接原高程；此坡面用于去除粗DEM最低值造成的岸边断崖，是视觉插值，**不是实时潮位、海底地形或实测滩坡**。仍保留原真实平面边界，不扩展海面。

`buildBeaches(scene,data,terrain.sample)` 使用地形同一表面采样再加3.5厘米，防止重叠面闪烁。基材是正常参与Babylon场景光照的StandardMaterial，emissive为黑色；不存在固定白昼发光效果。暖浅干沙向深色低饱和湿沙渐变，湿沙范围约21米为视觉估计。

两张1024²原创程序贴图分别提供细砂颜色与微弱砂纹凹凸；世界UV为7.5米周期，不按整个沙滩拉伸。贴图启用mipmap、三线性和8倍各向异性；凹凸强度随视距降低，2200米外归零。纹理不直接位移几何，避免砂粒导致远景抖动。近岸小岩石1800米外隐藏。

## 性能与检查

- 11个沙面绘制网格共享1个沙材质；岩石合并为额外1个绘制网格、1个材质。
- 沙面20,012顶点、36,524三角形；rock预算上限42块、每块48三角形，实际数量由源轮廓限定。
- 沙滩JSON约0.87MB，需经HTTP压缩；两张程序贴图共约8MB GPU基础RGBA内存，加mipmap约10.7MB。
- NullEngine检查全部顶点有限、索引有效、源沙面顶点不越界、平均normal.y约0.998、dispose无网格残留。
- 主场景地形、沙面和地面碰撞必须共用同一采样坡面；单独将沙面降低却保留2.4米地形会遮挡沙面，属于集成错误。
