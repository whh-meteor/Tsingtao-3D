# 青岛电视塔与市政府主楼：模型依据

核对日期：2026-10-14。代码 `src/civic-buildings.ts`，数据 `public/data/civic-landmarks.json`。坐标为项目 AEQD 原点经度120.3163、纬度36.0603，X东/Z北，1单位=1m。照片用于观察形制，程序纹理与文字均为原创；原图只在忽略的 `artifacts/heritage-research/` 研究目录，不进入public或发布包。

## 青岛电视塔

真实位置来自 `way/179057050`，质心 `[3058.17,950.44]`。OSM 的圆形占地约60m宽，对应塔基综合体；不能误当成上部60m宽的观光舱。OSM 明确 `height=232`、`start_date=1994`、电视通讯塔名称标签。模型最高点严格为地面基准+232m，不把山体海拔加入“建筑高度”。山体依照主场景DEM，不在本模块造假山。

实际查看资料：

- [OSM 原始塔轮廓与标签](https://www.openstreetmap.org/way/179057050)：平面与232m高度控制值。没有取得施工测绘图，OSM数值不等于测绘证明。
- [青岛新闻网2019年塔上实拍报道](https://news.qingdaonews.com/wap/2019-05/08/content_20350105.htm)：报道太平山约116m海拔及20世纪90年代观光塔。旧照片链接现已404，未将失败链接冒称已看外观图。
- [青岛日报2025年现场介绍](https://epaper.qingdaonews.com/qdrb/html/2025-08/19/content_144596_2530338.htm)和实际查看的[现场钢构架照片](https://epaper.qingdaonews.com/qdrb/resfile/2025-08-19/07/11149448_rbzt1_1755226926885_b.jpg)：可见公开空间中银灰钢柱、横腹杆与穿透构架。报道中的“231m观景平台”是场所高程类标注，不能将其误设为距本地地面231m的塔内楼层。
- 摄影者“田田田880”的[电视塔外观作品页](https://tuchong.com/1849938/15989548/)，已实际查看[具体原图](https://photo.tuchong.com/1849938/f/31425072.jpg)：收腰钢构腿与腹杆、细长中央通道、圆盘观光层、三角玻璃球舱、球舱上白环小舱、三段天线构架、红白红杆尖。
- 实际查看的[夜间外观摄影图](https://b0.bdstatic.com/3d31953635f17817a4ccbe885c3e7b52.jpg)，[摄影者原发布页](http://mbd.baidu.com/newspage/data/dtlandingsuper?nid=dt_4565621270895323484)：用于观察球舱网格的紫蓝灯、内筒弱暖光、天线钢构的照明边界。不把其灯效视为当前每晚固定节目表。

模型包含三组主要加粗腿部弦杆和重复次弦、横腹杆/斜腹杆，基部逐渐收腰，顶部连续分段钢桅杆；主体保持透空，不替换成白色实心圆柱。中央升降通道比钢构外包络细得多。圆盘下层、玻璃观光层和上部较小平台形成三层可辨体块，球舱另行建模，保留三角玻璃网格和上方白环小舱。

## 青岛市人民政府主楼

政府名称/地址来自 `node/11432724805`，点位 `[5515.44,732.54]`。其落在真实弧形办公楼 `way/275858482` 内；28个OSM轮廓点控制整个曲折/弧形主体，不将其简化成任意矩形楼。轮廓质心约 `[5516.08,728.44]`。

- [青岛市政府信息公开指南](https://www.qingdao.gov.cn/zwgk/szfgk/gkzn/)：官方说明香港中路11号、市级机关一期办公大楼。
- [青岛市政府办公厅官方介绍](https://www.qingdao.gov.cn/zwgk/xxgk/bgt/gkml/jgxx/202112/t20211214_4002884.shtml)：再次确认官方办公地址；不把页面联系方式等无关信息写进场景。
- 摄影者 Scorpius 的[办公楼实景作品页](https://scorpius.tuchong.com/69832612/)，已实际查看[原图](https://photo.tuchong.com/1006851/wp/361156860.jpg)：浅暖灰石端部、连续弧形格栅玻璃、横竖浅色石框、中央低入口棚、前方独立广场，后面另有更高的办公楼。
- 另实际查看[街面外观照片](https://qimg4.youxiake.com/upload/201908/15/68271565838672.jpg)：用于核对入口棚和正面弧形曲率，不能仅凭透视照片反推测绘坐标。

OSM `building:levels=12` 是楼层标签，`height=38.4` 是数据提取器用12×3.2m得到的估算，不是官方公布的准确楼高。模型保留38.4m的米制高度控制；临街照片可辨的八组主要玻璃格栅横带按照片绘制，**不宣称八个立面网格等于实际楼层数**。窗距、石框、端部窗带、入口棚24m宽与约5.2m高均为照片估计。

主入口采用名称节点投影到朝南的最近真实前立面，避免把任意最长翼段中点当作入口。后面的高楼、两侧会议建筑与广场均不是这一个主楼轮廓；本模块只排除 `way/275858482` 通用楼体，不把整个政府院落删掉。两个广场和五月的风由独立公园/广场模块负责。

## 工程接口与验证

`buildCivicBuildings(scene,data,shadows,sampleHeight)` 返回 `meshes`、`collisionMeshes`、`excludedBuildingIds`、`views`、`setDetail(distance)`、`setNight(strength,time)` 与 `dispose()`。排除ID为 `way/179057050`、`way/275858482`。相机视点ID为 `tv-tower`、`city-government`。

共享材质合批：20个网格，其中2个隐藏碰撞体、2个仅夜间启用的灯带批次；近景白昼最多16个启用可见批次，总68,594三角形。球舱三角格、屋冠细杆、栏杆和天线小平台细部在1800m外关闭，钢腿主体、玻璃球舱和主天线保持。没有为每个钢杆建立独立Mesh或物理刚体。

夜景由0–1强度控制：电视塔细青紫灯带和玻璃内的弱光、市政府约1/5窗格的弱暖光与入口字样；石墙、整块屋顶、混凝土基座不发光。白昼恢复原色、关闭两个灯带网格。夜景是实景启发的游戏表现，不复制现行灯光控制节目。

NullEngine检查通过：所有顶点有限、索引有效；最高电视塔点距地面232m；市府所有屋顶三角形朝上；无整墙自发光，夜间强度归零完全清除发光；LOD和dispose可执行且无残留Mesh。TypeScript检查通过。实际视觉效果与地形衔接由主场景浏览器QA继续核对。

限制：无室内、无结构工程精算、无机电设备或杆件逐件测绘；本轮平面/高度控制值与照片估计分别列出。后续可使用授权测绘或GLB模型替换局部构件，保持相同坐标和接口。
