# v0.4 场景与表现

建筑、道路、沙滩和地铁均使用 OSM 的真实平面位置。远景由 23,758 栋建筑的最小旋转包围矩形简化而成，仍使用原始高度或明确估高。近景旧城保留实际轮廓和红瓦屋顶；区域中景按完整 8km 组替换远景，加载不全时继续显示远景，避免空白和两套楼体重叠。高度切换采用 8/11km 滞回。

崂山新增 80m 网格（瓦片原始像素约31m），细网格最高采样1091.74m。1132m是OSM巨峰点的高度标签，与采样格网最大值不同。山地没有垂直拉伸。浮山40m和旧城32m网格继续保留。坡度、真实高程及建筑占地密度生成地表色彩；城市灰绿颜色不是完整土地利用分类。细网格边缘3格仅为接缝平滑，原始 f32 不改写。

11处自然沙滩保留真实轮廓与孔洞，湿岸从0.12m插值至内部DEM；这是游戏视觉坡面，不是潮位或海底测量。原地面通过约3m透明遮罩切除沙滩内部；周围地形使用8m/40m渲染替换，近景碰撞取细网格。8m表示重采样渲染间距，不能视为DEM精度提升。海岸石墙在真实沙滩处让开。

地铁8条线、105独立way沿地形显示移动光带；未跨越OSM缺口补直线。光带宽度随视角变化以便阅读，地面高度用于地图展示，不能据此判断地下轨道埋深、当前运营范围或实况列车。站点保存在数据中。

夜间楼窗、栈桥路灯、历史建筑窗户、市府窗户与电视塔灯带亮起。139栋真实沿海高层候选参与循环彩色扫光；名单不是官方核定参演楼群，节目为独立视觉模拟。无实况节目、天气或灯幕视频。远处窗格逐渐简化为整体弱灯，减少高频细节缩放闪烁。

缩放持续保留同一鼠标地理锚点，并拒绝近地平线的极远交点。道路排除旧城与区域两层重复面；对数深度、FXAA、mipmap、光空间阴影像素对齐和渐淡阴影共同降低跳动。仍需根据终端硬件评估帧率，不能保证每台设备相同。

地标标签为屏幕空间小幅上下浮动，点击可导航；控制面板“浮动标签”按钮可显示/隐藏全部标签。“收起面板”收起光海面板，顶部“光与海”重新展开。地铁光带与灯光秀独立开关。

v0.4.1修复远景沙滩变黑：Babylon StandardMaterial 会上传凹凸贴图强度的倒数，不能用 `level=0` 关闭凹凸。近景强度保持正数并平滑减弱，超过2200m使用共享沙色纹理、无凹凸贴图的独立远景材质。往返缩放的回归测试检查所有倒数有限，且近景细节能恢复。
