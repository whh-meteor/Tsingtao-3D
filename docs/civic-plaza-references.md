# 五四广场、五月的风及市府前场复原依据

核对日期：2026-10-14。`src/civic-plazas.ts` 创建可游戏漫游的实景资料支持外观模型，平面由真实OSM几何控制，细部不是施工测绘模型。

## 官方和真实照片依据

- [青岛政务网：五四广场](https://www.qingdao.gov.cn/yfqd/qdwl/cjfw/wyqgy/202009/t20200903_520360.shtml)，2020-09-03。广场在市级机关办公楼南侧，1996年建，约10万平方米；东海路分南北区，北区以绿荫大道、草坪和中央喷泉为主，南区包括露天舞台、点阵喷泉和观海迎月台；雕塑采用螺旋向上的钢体组合。这些事实控制布局语义，官方总面积不代替细部OSM边界。
- [青岛新闻网：“五月的风”运输史话](https://news.qingdaonews.com/wap/2023-06/01/content_23450055.htm)，2023-06-01。钢板雕塑，高30米、直径27米、重500余吨，采用旋转腾升的造型。这是模型高度和最大跨度的控制来源。
- [中国天气网：五四广场](https://www.weather.com.cn/shandong/qingdao/qdly/jdjs/09/1013639.shtml)，2010-09-19。同样给出30米高、27米直径以及螺旋钢体结构，作尺寸交叉验证。
- [青岛日报2023-03-20第03版](https://epaper.qingdaonews.com/qdrb/resfile/2023-03-20/03/qdrb2023032003.pdf)，照片“从海上眺望五四广场”，摄影王雷。已实际下载PDF并渲染检查：中心红色螺旋雕塑、环形平台、环状与分区绿地、灰色海滨步道、南北轴线及广场与浮山湾之间的曲线边界。参考PDF和渲染页分别存ignored `sources/civic-plaza-reference.pdf`、`artifacts/civic-plaza-reference.png`，不随站点打包。
- [青岛政务网：五月，追光吧！青岛！](https://www.qingdao.gov.cn/zwgk/xxgk/whly/gkml/gzxx/202605/t20260526_10609084.shtml)，2026-05-26，描述夜间五月的风与浮山湾楼宇灯光。这里只复原雕塑照明和少量小地灯，不据此编造整片广场发光或官方灯光秀节目。

不同报道对雕塑重量有500余吨与700吨差异；重量不参与游戏模型，本轮不以其做工程结论。未取得黄震原设计的三维或钢构件加工图，螺旋圈数、板片厚度、截面、细部弯曲与夜间投光位置均为照片参考估计。红色是程序材质，不是照片复制。

## 地理与模型约束

`public/data/civic-landmarks.json` 为另一数据任务整理，来源OSM PBF 2026-10-11与2026-10-14官方map API局部数据；OSM © OpenStreetMap contributors，ODbL1.0。模型坐标采用项目WGS84/AEQD，1单位1米。

- 五月的风真实雕塑 footprint 是 **way/539970693**，中心 **x=5752.32，z=103.15**；不使用同名商业地块中心替代。
- 五四广场南区铺装 relation/7929938、北区铺装 relation/7929937 保留各自多边形及真实内孔，不铺成矩形。绿地使用实际`planting`草坪/园地轮廓，不把park-outline全部当草坪。
- 补充50处实际地物中32处planting、10处paved-plaza、1处fountain、7处park-outline范围。仅真正植被与铺装/喷泉类型生成对应表面。
- 小型地灯沿真实OSM footway/pedestrian/path走向布置；真实路径决定位置范围，灯数、间隔、样式未测绘，是近景示意。
- 市府前场使用实际局部铺装/绿地数据，市府主楼由另一个建筑模块处理。本模块不伪造门前大矩形或复制整个政府楼足迹作为广场。

雕塑用闭合厚板截面沿连续螺旋路径扫掠，并加入中央上升、扭转风片；没有用红球或简单圆锥填满整体。外形控制30米总高、最大跨度约27米，截面细节和连接位置为近似。底座紧凑，周边环形铺装线仅落在真实铺装范围内。草坪、铺装、灯具、喷泉和树木都采项目真实地形高程；没有凭空抬高广场。

## 材质、夜景与性能

铺装使用原创灰色花岗岩砖纹与世界米制斜向UV，启用mipmap/三线性/各向异性；绿地与地面均正常接受太阳/月光。三束SpotLight只作用于雕塑，暖色投光照出钢片层次；地面灯具仅有细小实体发光，整块铺装、草坪不发光。

全部重复构件按材料合批；雕塑560段、每段6边厚板截面，主体约6720三角形，加中央风片约220三角形。地形铺装按11米最大边长递归细分以顺应真实高程，保留OSM内孔。树木预算170株；树、微地灯、喷泉水柱2300米外隐藏。SpotLight includedOnlyMeshes严格限定雕塑，不将三个投光灯施加到整个城市。

几何验证需检查坐标/索引/法线有限、铺装顶面朝上、雕塑中心接近真实OSM位置、最大高度30米且跨度约27米；dispose必须释放灯、纹理、材质与网格。
