# 信号山、小鱼山公园外观复原依据

资料核对日期：2026-10-13。`src/hill-parks.ts` 为照片与公开资料支持的游戏外观模型，不是保护工程测绘成果。1 Babylon 单位 = 1 米；平面位置沿用项目 WGS84 / AEQD 坐标，建筑基准、步道、树木均调用项目 DEM，不生成假山。

## 可核实建筑事实

- [青岛政务网：信号山](https://www.qingdao.gov.cn/yfqd/qdwl/cjfw/wyqps/202009/t20200909_519804.shtml)：海拔98米，公园6.3公顷，山顶3幢红色蘑菇楼、旋转厅等。模型保留三楼，并不把98米误当建筑高度。
- [青岛政务网：信号山公园](https://www.qingdao.gov.cn/yfqd/qdwl/cjfw/wyqgy/202009/t20200903_520367.shtml)：龙山路17号，1984年建园；可核对名称、海拔与面积。
- [青岛日报 / 观海新闻：夏日打卡信号山公园](https://www.dailyqd.com/guanhai/189290_2.html)，2022-06-16，摄影于滈。已实际查看照片：圆形暖色石砌基座、红色球状观景舱、中间连续环窗、舱下白色径向支撑、石基座拱形开口。照片仅用于形制和材质参考，未复制为贴图。
- [山东地方志资料：园林建筑及其他建筑](https://shandong-chorography.org/database/b2/section/42/article/42/)（原地方志资料存档）：览潮阁三层八角，高18米，绿琉璃瓦、白色环廊雕栏；东侧拥翠亭方形三层飘台，西侧碧波亭六角；相连曲廊有海洋主题瓷板。此网站为原省级地情资料的公开存档，而不是现行政府门户。
- [青岛日报：小鱼山——山不在高，灵境天成](https://www.dailyqd.com/channelzt/2020-09/02/content_521173.htm)，2020-09-02：再次确认览潮阁18米、三层八角，园区山体海拔约60米。
- [青岛新闻网：航拍小鱼山公园](https://news.qingdaonews.com/qingdao/2017-02/17/content_11939453_all.htm)，2017-02-17：绿色瓦、红柱、鱼头挑檐、海洋瓷板额枋、西六角亭东四角亭。
- [青岛新闻网：公园改造后展现古典之美](https://qingdaonews.com/content/2013-01/11/content_9569387.htm)，2013-01-11：绿瓦、彩绘与鱼形瓦饰；三亭、连廊均修缮。参考了[Trip.com公开实景照片](https://th.trip.com/moments/detail/qingdao-5-138509261/)核对三层屋檐、白色椽子及红柱的外观，不复制照片内容。
